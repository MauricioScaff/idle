## Prompt inicial

Use case: stylized-concept.
Asset type: ONE production pixel art SPRITE SHEET for an isometric idle game about an IT technician's tiny server closet, early 2000s vibe.

Create exactly 12 separate object sprites on a single image. Arrange in a spacious 4-column by 3-row loose grid, with generous completely empty magenta separation. Use a wide 3:2 landscape sheet. The small props must stay small relative to the desk and tower; do not enlarge them to fill their cells.

STRICT ART RULES:
True 2:1 isometric projection throughout, like Habbo Hotel / SimCity 2000. For EVERY object use exactly the same camera orientation: its TOP, LEFT face and RIGHT face are visible, with the front vertical edge pointing toward the viewer. Horizontal ground-plane edges slope at exactly 1 vertical pixel per 2 horizontal pixels. Do not use front view, side view, dimetric variations, or perspective vanishing points. Parallel edges remain parallel.
Uniform top-left lighting: LEFT faces lighter, RIGHT faces darker, tops lightest.
Real chunky pixel art: deliberately low-resolution sprites, clearly visible crisp square pixel clusters, 1 logical pixel dark outlines, one cohesive limited palette of approximately 32 colors for the entire sheet. Nearest-neighbor style integer enlargement of a low-resolution sheet, roughly 576x384 logical pixels enlarged uniformly 3x. No tiny high-resolution texture.
Background must be ONE absolutely flat solid color, exact magenta RGB(255,0,255) / #FF00FF across the entire canvas, between sprites and in all holes between legs, chair components and cables. OPAQUE MAGENTA background, not transparent. No floor tiles, ground plane, cast shadows, ground shadows, drop shadows, frames, cell boundaries, borders or decorations.
NO TEXT, NO LABELS, NO LETTERING, NO NUMERALS anywhere. The CRT screen should suggest terminal output with a few short abstract green pixel dashes only, not actual characters.
No blur, no gradients, no anti-aliasing, no smooth 3D rendering, no glossy reflections.
Objects must never touch or overlap another sprite. Every object is entirely visible including cables, antennae and legs, with generous safe margins.
All objects share the same physical scale. The tower case is approximately as tall as the DESK WORK SURFACE; the CRT sits above that surface. The coffee mug is a genuinely tiny prop relative to the tower. Antennae and cables use readable 1-logical-pixel outlines.
